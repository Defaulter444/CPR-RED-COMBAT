# REDLINE COMBAT 0.2.1

Из REDLINE полностью удалён учебный интерфейс. В установленном модуле больше нет кнопки «Учебный пример», отдельного демонстрационного окна или API `openDemo`. В ZIP входят только файлы рабочей боевой панели; демосцена, её изображения и SDK прототипа исключены.

Реальные действия персонажа сохранены: атаки, урон, режимы оружия, боеприпасы, навыки, инициатива и очередь боя работают через штатные диалоги и чат Cyberpunk RED. Логика действий, проекция состояния и проверки прав в этом обновлении не менялись.

## Установка и обновление

**Foundry → Add-on Modules → Install Module → Manifest URL:**

```text
https://raw.githubusercontent.com/Defaulter444/CPR-RED-COMBAT/main/distribution/module.json
```

Прежний адрес установки сохранён. Включите **REDLINE COMBAT** через **Manage Modules**. Для [ручной установки скачайте redline-combat.zip v0.2.1](https://github.com/Defaulter444/CPR-RED-COMBAT/releases/download/v0.2.1/redline-combat.zip), остановите сервер и замените папку `Data/modules/redline-combat` целиком. Это также удалит оставшиеся файлы демонстрации от предыдущей версии.

Поддерживается **Foundry v12**, адаптер действий рассчитан на **Cyberpunk RED Core 0.92.4**. Перед обновлением кампании сохраните предыдущую папку модуля. ZIP не содержит Foundry, систему или данные мира.

## Что остаётся доступным

- **Shift + R** и кнопка REDLINE в инструментах токенов показывают или скрывают HUD.
- Оружие, режимы атаки, броски урона, перезарядка и выбор патронов доступны в карточке персонажа.
- Быстрые и выбранные навыки, инициатива, спасбросок смерти и открытие штатного листа сохранены.
- Доступны обновление панели, очередь инициативы и отдельная команда GM «Следующий ход».
- Сохраняются API `open`, `close`, `toggle`, `refresh`, `getState` и совместное оформление с [Night City UI](https://github.com/Defaulter444/night-city-ui).

Исторический браузерный прототип остаётся в исходном репозитории как исследовательский материал и не устанавливается в Foundry.

## Проверки

Пройдены **77 автоматических тестов REDLINE**, включая новую регрессию: учебной кнопки нет, настоящие команды панели остаются доступны. Проверены синтаксис JS/Python, публичный API и состав ZIP — **11 файлов**, без каталога `demo`, шаблона `demo.hbs` и изображений прототипа. `actions.js`, `capabilities.js`, `state.js` и production-часть стилей действий сохранены без изменений.

В изолированном мире Foundry 12.331 / CPR 0.92.4 проверены клиенты Player и Gamemaster при 1280 × 720: учебного пункта нет, очередь боя отображается, карточка персонажа раскрывается с оружием, патронами и навыками. Подробный [QA.md](https://github.com/Defaulter444/CPR-RED-COMBAT/blob/main/foundry/redline-combat/QA.md) отдельно сохраняет более широкие боевые проверки 0.2.0. Рабочие кампании не изменялись.

## Ограничения и откат

HUD создаёт системные броски урона; применение урона к цели выполняется штатными командами в чате. Автоматическое применение урона, синхронные запросы защиты между клиентами и автоматизация NET не добавлены. Foundry v13+, другие версии CPR и экраны уже 1024 px не входят в проверенный набор.

Для отката отключите модуль, остановите сервер и восстановите сохранённую папку предыдущей версии целиком. Откат интерфейса не отменяет совершённые игровые действия, расход патронов и изменения инициативы.
