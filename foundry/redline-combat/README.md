# REDLINE COMBAT — Experimental Preview 0.1.1

Устанавливаемый модуль для **Foundry v12.343–12.999 / Cyberpunk RED (`cyberpunk-red-core`)**. Это первый пакет для самостоятельной проверки интерфейса в мире. Интеграция изучена по API v12 и исходникам CPR v0.92.4; запуск в лицензированной Foundry в этой среде не выполнялся.

## Установка

1. В Foundry откройте **Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:

   ```text
   https://raw.githubusercontent.com/Defaulter444/CPR-RED-COMBAT/main/distribution/module.json
   ```

3. Нажмите **Install**, зайдите в отдельный тестовый мир Cyberpunk RED и включите **REDLINE COMBAT — Experimental Preview** в **Manage Modules**.
4. HUD появится после перезагрузки мира. Выберите свой токен или назначьте персонажа пользователю. **Shift+R** и кнопка с молнией в инструментах токенов показывают / скрывают HUD.

Если установка по URL недоступна, скачайте `redline-combat.zip` со страницы [релиза](https://github.com/Defaulter444/CPR-RED-COMBAT/releases/tag/v0.1.1), распакуйте так, чтобы manifest находился в `Data/modules/redline-combat/module.json`, и перезапустите Foundry.

## Что работает в пакете

- Чтение настоящей очереди боя, инициативы, текущего хода и раунда. Выбранный персонаж отмечается отдельно от текущего хода.
- Чтение HP, отслеживаемой в системном листе брони головы/тела, экипированного оружия и магазина своего персонажа. Для GM доступны подконтрольные ему персонажи. Панель не вычисляет урон или правила брони.
- Выбор доступного участника очереди меняет только локальное отображение HUD; управление токеном на сцене продолжает работать отдельно. Выбор токена возвращает HUD к нему.
- Видимые цели на сцене; скрытые участники и невидимые цели исключаются из проекции игрока. Ресурсы чужого персонажа в HUD игрока не передаются.
- Открытие штатного листа персонажа. **«Следующий ход»** — явная команда GM штатному трекеру `Combat.nextTurn()`. Это единственное действие HUD, меняющее документ боя; при загрузке, выборе и обновлении документы не записываются.
- **«Демонстрационный просмотр»** открывает отдельное окно с учебным сценарием REDLINE: подготовка атаки, защита, результат, GM и NET. Учебные значения и роли не связаны с текущим миром. CSS демо изолирован в iframe.

## Границы версии

Настоящие атаки, броски, расход патронов, применение урона, запрос защиты между клиентами и NET automation ещё не подключены. Для игры используйте штатный лист и трекер системы. Демонстрационный GM-переключатель не даёт прав в мире.

Проверки state/projection и browser host fixture используют модели API, а не лицензированный Foundry server. Они проверяют интерфейс, фильтрацию и cleanup; совместимость при установке в настоящий мир требует вашей проверки. При проблеме приложите версию Foundry/CPR, текст ошибки консоли и шаги воспроизведения к [issue](https://github.com/Defaulter444/CPR-RED-COMBAT/issues).

Настройки HUD сохраняются для текущего клиента. Стандартный tracker, hotbar и sidebar не заменяются.

## API и разработка

После `ready`:

```js
const redline = game.modules.get('redline-combat').api;
await redline.open();
redline.openDemo();
redline.getState(); // новая безопасная read-only DTO, без сырых документов
await redline.close();
```

Сборка из корня репозитория: `python3 build-module.py`. Она создаёт `dist/module.json`, `dist/redline-combat.zip`, `dist/SHA256SUMS.txt` без npm-зависимостей. Для локального тестирования скопируйте содержимое ZIP в каталог модулей.

В пакет входят только новые исходники REDLINE и собственные SVG демо. Исходники исследованных сторонних модулей в ZIP не включены. Общая лицензия новых исходников пока не выбрана; публикация preview не устанавливает отдельную открытую лицензию.
