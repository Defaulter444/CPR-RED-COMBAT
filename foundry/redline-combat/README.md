# REDLINE COMBAT — 0.4.0-preview.2

Предварительный релиз для **Foundry 12.331 / Cyberpunk RED Core v0.92.4**. Архив предназначен для отдельного тестового мира. [Страница предварительного релиза](https://github.com/Defaulter444/CPR-RED-COMBAT/releases/tag/v0.4.0-preview.2). Стабильный канал сохраняет версию 0.3.2.

## Действие, результат, следующий шаг

После подтверждения штатного броска в доке появляется карточка с названием действия, оружием или навыком, доступным вам итогом и пояснением следующего шага. Успех операции, отмена и ошибка различаются текстом, цветом и значком. Выполненный бросок не означает успешного попадания.

- **«Открыть чат»** открывает оригинальную карточку этого броска в штатном ChatPopout с кнопками системы.
- **«Урон при попадании…»** открывает штатный бросок урона для оружия и режима исходной атаки, даже после выбора другого оружия на панели. Перед открытием заново проверяются персонаж, права, оружие и доступность режима. Для подавления такого продолжения нет.
- Бросок урона показывает native итог; отдельный критический бонус CPR указан отдельно. Применение к HP и броне выполняется штатными кнопками чата.
- **«Ранее в этой сессии»** показывает предыдущие четыре действия. История привязана к точному персонажу/токену, хранится только на текущей странице и очищается при перезагрузке.
- Слепые и недоступные результаты не показывают число, критический бонус, результат спасброска или ссылку. Доступ повторно проверяется при обновлении панели и перед открытием чата.

После завершённого броска каталог закрывается. На маленьком экране док прокручивает только свою среднюю область до новой карточки; обновление без нового действия сохраняет положение прокрутки. Фокус пользователя и положение сцены не меняются.

## Состояния и быстрый доступ

Рядом с HP отображается нативное состояние ранений, критические травмы и активные эффекты выбранного персонажа. Отключённые и подавленные эффекты исключаются. Названия не заменяют расчёт модификаторов CPR; интерфейс не вычисляет состояние по собственным порогам процентов HP.

Навигация **Бой / Арсенал / Навыки** связывает основные команды. Арсенал показывает экипированное оружие; выбор изменяет только отображение на клиенте. Звезда у навыка добавляет его в избранное, до восьми на персонажа/токен. Быстрый бросок открывает настоящий CPRRollDialog. Избранное сохраняется на клиенте после перезагрузки.

Переходы панелей, нового результата, оружия и показателей запускаются по изменению состояния. Обычный refresh не повторяет входную анимацию. Шестерёнка управляет масштабом 55–125% и плавными анимациями; системное уменьшение движения имеет приоритет. Навигация, избранное и строка состояния остаются доступны при прокрутке.

## Установка в тестовый мир и откат

В Foundry → Add-on Modules → Install Module вставьте отдельный Manifest URL:

```text
https://github.com/Defaulter444/CPR-RED-COMBAT/releases/download/v0.4.0-preview.2/module.json
```

Ниже приведён вариант ручной установки из ZIP.

1. Остановите тестовый Foundry и сохраните прежнюю папку `Data/modules/redline-combat`.
2. Извлеките папку `redline-combat` из preview ZIP в `Data/modules`, затем запустите сервер.
3. Включите модуль в тестовом мире Cyberpunk RED, выберите свой токен и разверните док. Shift+R показывает и скрывает HUD.
4. Для отката остановите сервер и верните сохранённую папку модуля.

В ZIP нет данных мира или Foundry runtime. Совместимость проверена с CPR 0.92.4; новые версии и сочетания сторонних модулей требуют отдельной проверки. Результаты проверки этой сборки перечислены в QA.md.

## Разработка и материалы

Код и интерфейс доработаны при помощи OpenAI Codex (GPT-6). Оригинальная подпись REDLINE подготовлена в ArtCraft EffectCraft 0.14.0. Визуальные переходы реализованы средствами CSS и Web Animations API. Демонстрационная сцена использует собственные SVG-портреты и силуэты; видео отмечено как демонстрация. Ресурсы Foundry и Cyberpunk RED Core используются из установленной системы во время работы и не входят в пакет модуля.


Этот адрес сохранён для пользователей предыдущих версий. Установите пакет и включите **REDLINE COMBAT** через **Manage Modules** в мире Cyberpunk RED.

Для ручной установки скачайте [redline-combat.zip v0.3.2](https://github.com/Defaulter444/CPR-RED-COMBAT/releases/download/v0.3.2/redline-combat.zip), остановите Foundry и распакуйте папку `redline-combat` в `Data/modules`. Manifest должен находиться по адресу `Data/modules/redline-combat/module.json`. Перезапустите сервер и включите модуль. При обновлении заменяйте папку целиком, сохранив предыдущую версию для отката.

Поддерживается только **Foundry v12**; текущая проверка выполняется на **12.331 / CPR 0.92.4**. Адаптер действий работает именно с CPR **0.92.4**. Для совместной работы с [Night City UI](https://github.com/Defaulter444/night-city-ui) обновите его до **0.3.5**. Перед применением обновления в кампании используйте отдельный тестовый мир. ZIP не содержит Foundry VTT, систему Cyberpunk RED, данные мира или специальные изображения тестовой сцены.

## Выбор персонажа и очередь боя

**Shift + R** и кнопка REDLINE в инструментах токенов показывают или скрывают HUD. Выберите своего токена или доступного участника очереди. У игрока также может использоваться назначенный персонаж.

Очередь видна **только после начала боя** в штатном трекере. Созданный бой с добавленными участниками до запуска её не показывает. Выбор персонажа меняет карточку HUD и не переключает текущий ход. **«Следующий ход»** — отдельная команда GM штатному трекеру боя. Игроку доступны только разрешённые персонажи и видимые участники/цели; настройки отображения сохраняются для текущего клиента.

## Оружие и броски

1. Разверните док кнопкой в углу. Выберите одно из экипированных оружий в центральном списке и доступный **режим**. В зависимости от оружия это обычная или прицельная атака, автоогонь либо подавление.
2. Нажмите **«Атака»**. В системном диалоге задайте модификаторы и подтвердите бросок. Боеприпасы расходуются по правилам CPR; отмена диалога не выполняет атаку.
3. Нажмите **«Урон»** для системного броска урона. **Применение к цели выполняется через штатные команды системы в чате.** HUD сам не уменьшает HP и броню цели; для подавления отдельный бросок урона недоступен.
4. **«Перезарядить»** вызывает системный `reload` и использует запас из инвентаря. Значок коробки **«Выбрать патроны»** вызывает `load` с выбором боеприпасов. Эти команды не создают дополнительный боезапас.
5. **«Навыки»** открывает прокручиваемую панель над доком. Если между очередью и доком мало места, навыки временно раскрываются поверх дока, сохраняя доступ к очереди и макросам. Разделы листа находятся слева, навыки справа; поиск фильтрует раздел. Кнопка **«Бросить — название навыка»** открывает штатный диалог. **«Другие броски»** раскрывает инициативу и спасбросок смерти. Выбор навыка сохраняется при обновлении карточки. Escape закрывает панель и возвращает фокус кнопке **«Навыки»**.
6. **«Инициатива»** доступна для персонажа в текущем бою. **«Спасбросок смерти»** включается при HP ≤ 0. **«Открыть лист»** возвращает к полному штатному листу.

Недоступные действия отключаются и имеют пояснение в подсказке. Во время выполнения команды кнопки и списки блокируются. Броски и применение урона — через диалоги и чат системы; REDLINE не заменяет формулы и правила CPR.

## Blackglass Dock и сворачивание

Развёрнутый док имеет три области: **портрет, HP и броня**; **оружие, его изображение, режим и патроны**; **цель, «Атака» и дополнительные команды**. Портрет и изображение оружия берутся из листа персонажа и предмета. При отсутствии изображения используется штатный значок.

Стрелка в углу сворачивает док в полосу с именем, HP, оружием и целью: **57 px при 100%**, около **46 px при масштабе по умолчанию 80%**. Раскрытие сохраняется в клиентской настройке `dockExpanded`. Выбранное оружие запоминается для персонажа **только в текущем сеансе страницы**, после перезагрузки страницы выбор сбрасывается. Это выбор отображения в HUD; экипировка в листе не меняется.

**Шестерёнка «Настроить размер REDLINE»** рядом со стрелкой открывает масштаб дока и очереди от **55 до 125%**, с шагом **5%**. Кнопка сброса возвращает **80%**. Та же клиентская настройка доступна в настройках модуля Foundry и сохраняется только для вас. Максимальная ширина дока при 100% — **1100 px**, при 80% — **880 px**; фактическая ширина дополнительно ограничена свободным местом на экране.

REDLINE пересчитывает отступы по фактическому положению сайдбара, инструментов, макросов и верхней навигации Foundry. Очередь начатого боя размещается ниже видимого таймера DEADLINE и возвращается вверх после его исчезновения. Без Night City UI показывается собственная шапка. Необязательный **Night City UI 0.3.5** добавляет общую навигацию и оформление Foundry; старые компактные ограничения и вторая кнопка сворачивания к новому доку не применяются.

Штатные листы, трекер, макросы и сайдбар остаются доступны. Устанавливаемый пакет содержит рабочую панель; учебное окно, его кнопка и API отсутствуют. Исторический браузерный прототип сохранён отдельно в исходниках репозитория и в ZIP не входит.

## Проверки и ограничения

Для **0.3.1 пройдены 99 автоматических тестов REDLINE**, для совместного **Night City UI 0.3.5 — 85 тестов**. Игровые действия и проверки прав используют прежний адаптер; API `open`, `close`, `toggle`, `refresh`, `getState` сохранены, `openDemo` отсутствует. Полные результаты приведены в [QA.md](QA.md).

Текущая живая проверка выполнена под Gamemaster в изолированном **Foundry 12.331 / CPR 0.92.4**. При **1672 × 941** док 80% занял **880 × 156,36 px** вместо прежних **1288 × 195 px**. При 55% — **605 × 108,11 px**. Масштаб 125% сохранился после перезагрузки; сброс вернул 80%. При начале боя с раунда 0 до 1 появилась очередь **880 × 64,36 px**; возврат с раунда 1 к 0 удалил её из DOM.

При **1024 × 768**, масштабе **125%** и развёрнутом DEADLINE очередь располагается ниже таймера, док прокручивается, а навыки высотой **300 px** помещаются между очередью и макросами. Escape закрывает навыки. Отмена штатного диалога атаки сохранила **5/8** патронов. Проверка завершена с масштабом **80%** и готовым свёрнутым таймером; рабочие кампании не изменялись.

Историческая база **0.3.0**: пройдены **93 автоматических теста REDLINE** и **59 тестов Night City UI 0.3.4**. Следующие живые результаты относятся к 0.3.0 и не заменяют проверку нового масштаба и видимости очереди.

В отдельном мире **Foundry 12.331 / CPR 0.92.4** проверен новый док при **1672 × 941**, **1280 × 720** и **1024 × 768**. Док и навыки размещаются между очередью и макросами; при 1024 px навыки прокручиваются, Escape возвращает фокус кнопке открытия. Под Gamemaster подтверждена атака с расходом **6 → 5 ровно один раз**, защита через Evasion Workflow **16 против атаки 9** и Атлетика **15**. Под Player открывается системный диалог атаки, отмена сохраняет **5/8** патронов; выбор чужого НПС в очереди и команда следующего хода отключены. Проверены отключение общего слоя Night City UI, восстановление через Alt + N и переключение общей темы.

Подробности и отдельно обозначенные исторические проверки 0.2.0 / 0.2.1 сохранены в [QA.md](QA.md). Прежние сценарии охватывают дополнительные режимы оружия, перезарядку, навыки и инициативу; они не заменяют проверку нового расположения. Рабочие кампании не изменялись.

Проверены свёрнутый и развёрнутый таймер DEADLINE и возвращение очереди вверх после паузы. При 1024 × 768 с развёрнутым таймером навыки временно раскрываются поверх дока, прокручиваются и закрываются по Escape; очередь и макросы остаются доступны.

Ветки ближнего боя и успешного спасброска смерти проверены только автоматическими тестами с моделями системы; отдельного живого сценария для них не было. В этой версии нет автоматического применения урона, синхронных запросов защиты между клиентами и автоматизации NET. Одновременные действия разных клиентов используют штатное поведение Foundry/CPR. Другие версии системы, Foundry v13+, мобильные экраны уже 1024 px и произвольные наборы сторонних модулей не входят в проверенный набор.

## Отключение и откат

Отключите модуль через **Manage Modules**. Для отката остановите сервер и восстановите сохранённую папку предыдущей версии; не смешивайте файлы разных релизов. Для полного удаления после отключения удалите папку `Data/modules/redline-combat` при остановленном сервере.

Откат интерфейса не отменяет уже выполненные атаки, расход патронов, броски и изменения инициативы. При сообщении об ошибке укажите версии Foundry/CPR, действие и шаги воспроизведения.
