# REDLINE COMBAT

**Версия 0.2.1** — панель управления персонажем и очередью боя для **Foundry VTT v12** и **Cyberpunk RED Core 0.92.4** (`cyberpunk-red-core`). REDLINE показывает данные выбранного персонажа и запускает настоящие действия через диалоги и чат системы: атаки, урон, режимы оружия, боеприпасы, навыки и инициативу. В 0.2.1 учебный интерфейс полностью удалён из устанавливаемого модуля; игровые действия сохранены.

## Установка в Foundry v12

В **Add-on Modules → Install Module → Manifest URL** вставьте прежний адрес модуля:

```text
https://raw.githubusercontent.com/Defaulter444/CPR-RED-COMBAT/main/distribution/module.json
```

Установите пакет, откройте мир Cyberpunk RED и включите **REDLINE COMBAT** через **Manage Modules**. Для ручной установки скачайте [redline-combat.zip v0.2.1](https://github.com/Defaulter444/CPR-RED-COMBAT/releases/download/v0.2.1/redline-combat.zip), остановите сервер и замените папку `redline-combat` в `Data/modules` целиком. Итоговый путь: `Data/modules/redline-combat/module.json`.

Поддерживается **Foundry v12**; для предыдущей версии 0.2.0 живая проверка выполнена на **12.331 / CPR 0.92.4**. Адаптер действий ограничен именно CPR **0.92.4**. Перед обновлением рабочей кампании рекомендуется проверить сборку в отдельном тестовом мире и сохранить предыдущую папку модуля. Foundry, система Cyberpunk RED и данные мира в ZIP не входят.

## Как пользоваться

1. Выберите своего токена или доступного участника очереди боя. У игрока также может использоваться назначенный персонаж. **Shift + R** и кнопка REDLINE в инструментах токенов показывают или скрывают панель.
2. У экипированного оружия выберите режим и нажмите **«Атака»**. Откроется штатный диалог Cyberpunk RED с модификаторами; подтверждённая атака расходует боеприпасы по правилам системы.
3. **«Урон»** создаёт системную карточку урона. Применение урона к цели выполняется обычными командами системы в чате; HUD не уменьшает HP или броню цели автоматически.
4. **«Перезарядить»** использует запас из инвентаря, а значок коробки **«Выбрать патроны»** вызывает штатный выбор боеприпасов. Эти команды используют системные `reload` и `load`.
5. Ниже оружия расположены быстрые навыки, список всех навыков, инициатива и спасбросок смерти. Инициатива доступна для персонажа в текущем бою; спасбросок смерти — при HP ≤ 0.

Текущий ход и выбранный персонаж — разные состояния. Выбор карточки не меняет очередь; **«Следующий ход»** отправляет отдельную команду GM штатному трекеру. Недоступные действия отключены с объясняющей подсказкой. Во время выполняемой команды кнопки блокируются, чтобы избежать повторного запуска.

Для общего оформления можно отдельно установить [Найт-Сити — общий интерфейс](https://github.com/Defaulter444/night-city-ui). В Blackglass карточка занимает **540 × 80 px**; **«Действия»** раскрывает область с запрошенной высотой **340 px**, полоса целей добавляет **32 px**. На ширине **1024 px** область ограничивается доступным местом и прокручивается; кнопка **«Свернуть»** остаётся доступной. Без Night City UI REDLINE сохраняет самостоятельную прокручиваемую панель.

## Проверки и ограничения

Для **0.2.1 прошли 77 автоматических тестов REDLINE**, включая отсутствие учебной кнопки и сохранение настоящих команд панели. Проверка API подтвердила сохранение `open`, `close`, `toggle`, `refresh`, `getState` и отсутствие `openDemo`. В собранном ZIP — 11 файлов; демосцена, её шаблон, изображения и SDK не включаются.

Живые сценарии **Player и Gamemaster** на Foundry 12.331 / CPR 0.92.4 и проверка размеров **1440 × 900 / 1024 × 768** относятся к предыдущей версии **0.2.0**: атака и отмена, автоогонь и отдельный урон, боеприпасы и перезарядка, прицельный режим, подавление, навыки и инициатива. Исторический отчёт сохранён в [QA.md](foundry/redline-combat/QA.md). В 0.2.1 отдельно проверены отсутствие учебного интерфейса, очередь и раскрытие настоящих действий персонажа у GM и Player в тестовом мире при 1280 × 720.

Ветки ближнего боя и успешного спасброска смерти покрыты автоматическими тестами с моделями системы; отдельного живого сценария для них в этом проходе не было. Нет синхронного запроса защиты между клиентами, автоматического применения урона или NET automation. Одновременные действия разных клиентов подчиняются штатному поведению Foundry/CPR. Foundry v13+, другие версии CPR, мобильные экраны уже 1024 px и произвольные сочетания сторонних модулей не входят в проверенный набор.

Чтобы откатить обновление, отключите REDLINE через **Manage Modules**, остановите сервер и восстановите сохранённую папку предыдущей версии. Не смешивайте файлы разных версий. Откат модуля не отменяет уже выполненные игровые действия, расход патронов или изменения инициативы.

## Разработка

Для запуска учебного прототипа нужен Python 3:

```sh
git clone https://github.com/Defaulter444/CPR-RED-COMBAT.git
cd CPR-RED-COMBAT
python3 -m http.server 8765
```

Откройте `http://localhost:8765/prototype/` или галерею `http://localhost:8765/`. Учебные HTML-файлы следует открывать через HTTP-сервер, а не через `file://`, чтобы браузер мог загрузить ES modules. Владелец репозитория также может включить статический сайт через [Settings → Pages](https://github.com/Defaulter444/CPR-RED-COMBAT/settings/pages); наличие репозитория само по себе не гарантирует развёртывание Pages.

Проверки текущего модуля выполняются из корня репозитория:

```sh
npm test
python3 build-module.py
```

`dist/` содержит ZIP, manifest и контрольные суммы. Исторические `validate.py`, `validate-examples.py` и `validate-module.py` относятся к прототипу и browser fixture; они не заменяют проверку настоящего Foundry.
